# Релизы и обновления

## Как это работает

1. Любой push в `main` запускает [release.yml](../.github/workflows/release.yml).
2. Workflow присваивает версию `<major>.<minor>.<номер запуска>` (например `0.1.12`) и создаёт черновик релиза `v0.1.12`. Затем параллельно на Windows и macOS прогоняет тесты и собирает установщики, подписанные ключом обновлений. Когда оба готовы, пишет `latest.json` со ссылками для `windows-x86_64`, `darwin-aarch64` и `darwin-x86_64` и публикует релиз. Если одна из сборок упала, релиз остаётся черновиком и пользователи его не увидят.
3. Установленное приложение проверяет `latest.json` при запуске и каждые 6 часов. Если версия новее, сверху появляется полоса «Доступна версия … · Обновить». По кнопке обновление скачивается, проверяется подпись, ставится и приложение перезапускается.

Крупный шаг (0.1 → 0.2 или 1.0) — поменять `version` в `apps/desktop/src-tauri/tauri.conf.json`; последняя цифра всё равно ставится автоматически.

## Установщики

- **Windows**: `Trufi.Cleaner_<версия>_x64-setup.exe` — русский язык, установка для текущего пользователя без прав администратора, ярлык в меню «Пуск». WebView2, если его нет, установщик скачает сам.
- **macOS**: `Trufi.Cleaner_<версия>_universal.dmg` — одна сборка для Apple Silicon и Intel, macOS 11 и новее. Для автообновления рядом лежит `Trufi.Cleaner_universal.app.tar.gz` с подписью.

## Настройка (один раз)

1. Репозиторий должен быть публичным: приложение скачивает обновления без авторизации.
2. Добавить секрет `TAURI_SIGNING_PRIVATE_KEY` (Settings → Secrets and variables → Actions → New repository secret) со всем содержимым приватного ключа подписи. Пароля у ключа нет.
3. Публичная часть ключа уже записана в `tauri.conf.json` (`plugins.updater.pubkey`). Если ключ потерян, нужно создать новый (`npx tauri signer generate`), заменить `pubkey`, а пользователям старых версий один раз переустановить приложение вручную.

Приватный ключ нельзя коммитить в репозиторий.

## Подпись для macOS (необязательно)

Без сертификата Apple приложение подписывается ad-hoc: работает, но при первом запуске macOS просит подтвердить его в настройках (см. README). Чтобы оно открывалось сразу, нужен аккаунт Apple Developer (99 $ в год) и сертификат **Developer ID Application**. Секреты репозитория:

| Секрет | Что это |
|---|---|
| `APPLE_CERTIFICATE` | Сертификат `.p12` в base64 (`base64 -i cert.p12`) |
| `APPLE_CERTIFICATE_PASSWORD` | Пароль от `.p12` |
| `APPLE_SIGNING_IDENTITY` | `Developer ID Application: Имя (TEAMID)` |
| `APPLE_ID`, `APPLE_PASSWORD`, `APPLE_TEAM_ID` | Для нотаризации: Apple ID, пароль приложения с appleid.apple.com, Team ID |

Если секретов нет, шаг просто пропускается.
