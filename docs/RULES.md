# Правила очистки

Пакет правил — файл TOML с заголовком `[pack]` и списком `[[rule]]`.

```toml
[pack]
id = "windows.apps"
name = "Программы"
os = "windows"        # windows | macos | linux | any
version = 1

[[rule]]
id = "app.discord.cache"          # уникальный; правило с тем же id в пользовательском пакете заменит встроенное
name = "Discord: кеш"
description = "Что это и что будет после очистки."
category = "apps"                 # system | browsers | apps | games | developer | logs | privacy | leftovers
risk = "safe"                     # safe | moderate | expert
paths = ["%APPDATA%/discord/Cache", "%APPDATA%/discord/Code Cache"]
close_processes = ["Discord.exe"] # подсказка «закройте программу»
```

## Поля

| Поле | По умолчанию | Описание |
|---|---|---|
| `paths` | — | Шаблоны путей. Каждое совпадение — папка, внутри которой чистим, или отдельный файл |
| `include` / `exclude` | все файлы / нет | Glob-шаблоны относительно корня: `"*.log"`, `"**/index.dat"` |
| `min_age_hours` | 0 | Не трогать файлы, изменённые недавно |
| `max_depth` | без ограничения | Глубина обхода (1 — только содержимое корня) |
| `remove_empty_dirs` | true | Удалять папки, опустевшие после очистки (сам корень остаётся) |
| `keep_newest` | — | Каждая подпапка — одна запись, N самых свежих остаются (старые версии программ). `0` — каждая подпапка отдельной записью, например резервные копии iPhone |
| `requires_admin` | false | Пометка «нужны права администратора» |
| `default` | `risk == "safe"` | Отмечено ли правило после сканирования |
| `special` | — | `"trash"`: корзина через API системы (на macOS — `~/.Trash`, нужен полный доступ к диску), `paths` не нужны |

## Переменные в путях

`%VAR%` без учёта регистра и `~` в начале. Неизвестная переменная — правило просто не применяется.

Windows: `USERPROFILE` (= `HOME`), `LOCALAPPDATA`, `APPDATA`, `PROGRAMDATA`, `PROGRAMFILES`, `PROGRAMFILES(X86)`, `PUBLIC`, `WINDIR`, `SYSTEMDRIVE`, `STEAM` (папка Steam из реестра).

macOS: `HOME` (и `~`), `DARWIN_USER_DIR` (папка над `$TMPDIR`: `"%DARWIN_USER_DIR%/T"` — временные файлы), `CONTAINERS` (`~/Library/Containers`, только при полном доступе к диску; без него правило просто не применяется).

Списки (правило проверяется для каждого значения):

- `%DRIVES%` — все фиксированные диски: `"%DRIVES%/NVIDIA"` проверит `C:\NVIDIA`, `D:\NVIDIA`, ... На macOS — домашняя папка.
- `%STEAMLIBS%` — все библиотеки Steam на всех дисках.

`*` и `?` работают в любом сегменте: `"%LOCALAPPDATA%/Google/Chrome/User Data/*/Cache"`.

## Уровни риска

- **safe** — кеш и временные файлы, которые владелец создаст заново. Выбраны по умолчанию.
- **moderate** — безвредно, но заметно: придётся заново скачать, войти или подождать пересборки.
- **expert** — нужен взгляд человека. Если записей не больше 200, пользователь выбирает их по одной.

Что бы ни было написано в правиле, защищённые папки (системные, документы, данные профилей браузеров) и корни уровня «весь диск», «вся папка пользователя» или «весь AppData» отклоняются.
