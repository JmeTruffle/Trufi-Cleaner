# Trufi Cleaner

Минималистичная утилита для очистки и оптимизации компьютера на **Windows 10/11** и **macOS 11+** (Apple Silicon и Intel).

- **Обзор**: оценка состояния системы (0–100) с объяснением, живые графики процессора и памяти, все диски, сеть, тяжёлые процессы и советы.
- **Очистка**: кеши системы, браузеров, программ, игр и инструментов разработки, журналы, корзина, остатки удалённых программ и крупные файлы на всех дисках. Сканирование ничего не удаляет.
- Мягкий «небесный» интерфейс со стеклянными карточками и маскотом, своя рамка окна, обновление в один клик.
- **Оптимизация**: автозагрузка (отключение обратимо, как в Диспетчере задач), установленные программы с запуском их деинсталлятора, тяжёлые процессы.
- **Драйверы** (только Windows): устройства с ошибками и обновления драйверов из Windows Update.

### Что отличается на macOS

| | Windows | macOS |
|---|---|---|
| Автозагрузка | реестр и папка автозагрузки | службы launchd (`LaunchAgents`, `LaunchDaemons`); отключение через `launchctl disable`, действует со следующего входа. «Объекты входа» открываются в Системных настройках |
| Удаление программ | запуск деинсталлятора | перемещение `.app` в Корзину через Finder (можно вернуть) или фирменный деинсталлятор из папки программы |
| Обновления системы | Windows Update | Software Update (`softwareupdate --list`) и история установок |
| Права | перезапуск от имени администратора | не нужны: для системных служб и программ из App Store macOS сама спросит пароль |
| Особые разрешения | — | **Полный доступ к диску**: без него не видны Корзина, кеш Safari, вложения Почты и данные программ из App Store |
| Драйверы | отдельная страница | нет: macOS обновляет драйверы вместе с системой |
| Что чистится | кеши Windows, браузеров, программ, игр, разработки | `~/Library/Caches`, `$TMPDIR`, журналы, браузеры (включая Safari), Electron-программы, Xcode (DerivedData, DeviceSupport, архивы), Homebrew, npm/pip/Cargo, прошивки и резервные копии iPhone, установщики `.dmg`/`.pkg` в Загрузках |

## Безопасность

- Удаляется только то, что было найдено сканированием и отмечено.
- Перед удалением каждый путь проверяется заново: защищённые папки (System32, WinSxS, Installer, Package Cache, документы, данные профилей браузеров и т.д.) недоступны для любых правил, включая пользовательские.
- На macOS так же защищены `/System`, `/Library`, `/Applications`, Документы, Фото, Почта, Сообщения, Связка ключей, iCloud Drive и облачные папки (`~/Library/CloudStorage`: Dropbox, OneDrive, Google Drive).
- Ссылки и junction-точки не обходятся, облачные файлы OneDrive не трогаются.
- Временные файлы младше суток пропускаются; файл, изменённый после сканирования, не удаляется.
- Остатки программ и крупные файлы никогда не выбираются автоматически, папки с возможными сохранениями игр помечаются.

## Разработка

Нужны Rust (stable), Node.js 22 и [зависимости Tauri](https://v2.tauri.app/start/prerequisites/).

```sh
cd apps/desktop
npm install
npm run tauri dev     # приложение с горячей перезагрузкой
npm run dev           # только интерфейс в браузере, с тестовыми данными (?os=macos — вид для Mac)
npm run tauri build   # Windows: установщик .exe; macOS: .app и .dmg в target/release/bundle
cargo test -p trufi-core -p trufi-platform
```

## Установка и обновления

Готовые установщики лежат в [релизах](https://github.com/JmeTruffle/Trufi-Cleaner/releases/latest). Каждый push в `main` выпускает новую версию для обеих систем, а приложение само предлагает обновиться.

**Windows**: скачать `...x64-setup.exe` и запустить, права администратора не нужны.

### macOS

1. Скачать `...universal.dmg` (подходит и для Apple Silicon, и для Intel), открыть и перетащить **Trufi Cleaner** в папку «Программы».
2. Пока приложение не подписано сертификатом Apple Developer, macOS при первом запуске скажет, что не может проверить разработчика. Нужно один раз разрешить:
   - macOS 15 и новее: открыть приложение, нажать «Готово», затем **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**;
   - macOS 11–14: в Finder нажать на приложение с Control (правый клик) → «Открыть» → «Открыть».
   Если macOS пишет, что приложение «повреждено», снимите карантин командой `xattr -dr com.apple.quarantine "/Applications/Trufi Cleaner.app"`.
3. Чтобы чистить Корзину, кеш Safari и данные программ из App Store, включите Trufi Cleaner в **Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску** (кнопка «Разрешить» есть в приложении) и перезапустите его.
